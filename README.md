# Email Risk Analyzer

## Overview
Email Risk Analyzer is a Python program that evaluates email content and identifies potentially unsafe messages. It helps users detect phishing attempts by scanning for suspicious phrases, unknown links, and requests for sensitive information.

## Features
- Detects urgent or threatening language
- Identifies links within email content
- Flags requests for sensitive information
- Classifies emails as Low, Medium, or High Risk
- Easy-to-use command-line interface

## Technologies Used
- Python
- Regular Expressions (re)

## How to Run
1. Save the code as `email_risk_analyzer.py`
2. Open a terminal in the project folder.
3. Run:
   ```bash
   python email_risk_analyzer.py
